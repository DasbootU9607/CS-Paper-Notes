# CS Paper Notes

This repository collects my reading notes for computer science and machine learning papers. The notes are written in Markdown and organized for review in Obsidian or directly on GitHub.

The goal is not only to summarize papers, but also to keep track of:

- **research questions** and motivation
- **main contributions** and core ideas
- **methods, architectures, and training details**
- **datasets, baselines, metrics, and results**
- **limitations, connections, and follow-up readings**

## Note Format

Each paper note follows a consistent structure:

1. **TL;DR** and core takeaway
2. **Research question**
3. **Main contribution**
4. **Key idea**
5. **Method**
6. **Architecture**
7. **Experiments / evaluation**
8. **Strengths and limitations**
9. **Connections and future reading**
